# Mika 云端

这里只放「Mika 云端」的安装包，不放代码。它是 [Mika](https://github.com/wangzan101/Mika)（Apache-2.0）的一个实验版本，供作者自己的 ds-agent 项目使用：在手机上连接作者自己的云端 Agent。

- 包名 `com.wangzan101.mika.cloud`，可以和官方 Mika 并排安装。
- App 内「关于 › 检查更新」从本仓库的 Releases 获取新版本。
- 调试签名，仅供作者本人使用。

This repository holds release APKs only, no source. It is an experimental build of [Mika](https://github.com/wangzan101/Mika) (Apache-2.0) for the author's own ds-agent project.
